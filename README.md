# MeowCast 🐈‍⬛

**Vibe code at the speed of thought.**

MeowCast is an elegant, system-wide dictation and AI analysis tool built for Windows. Hold a key, speak your thoughts, and release to see your words land instantly wherever your cursor blinks — in your IDE, terminal, browser, or chat. 

## Features
- **Hold. Speak. Release. Land.** — One global hotkey to rule them all. No need to switch windows.
- **Privacy First** — Run purely on-device using local Whisper models, or connect your own API keys for blazing fast cloud transcription.
- **Multi-Modal AI Tips** — Use Google Gemini Vision or OpenAI GPT-4o to analyze your screen instantly and give you contextual advice.
- **AI Skills** — Define custom prompt wrappers (like "Refactor this code", "Formal Email") and apply them on the fly to your dictated text.

## Download
Download the latest Windows installer (`.exe`) from the [Releases](https://github.com/catevildev/MeowCast/releases/latest) page.

## Requirements
- Windows 10 or Windows 11
- (Optional) API Keys for OpenAI, Groq, or Google Gemini if you want to use cloud-based features.
